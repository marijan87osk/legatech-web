Što utječe na cijenu web stranice?

Cijena web stranice može se kretati od nekoliko stotina do nekoliko tisuća eura, a kod kompleksnih projekata i znatno više. Razlika nije samo u tome koliko stranica web ima.

Cijena web stranice može se kretati od nekoliko stotina do nekoliko tisuća eura, a kod kompleksnih projekata i znatno više.

Razlika nije samo u tome koliko stranica web ima.

Na cijenu utječu:

  • opseg projekta
  • količina sadržaja
  • dizajn
  • broj različitih tipova stranica
  • posebne funkcionalnosti
  • SEO zahtjevi
  • integracije
  • migracija postojećeg weba
  • unos sadržaja
  • testiranje
  • održavanje nakon objave

Zato dvije web stranice koje na prvi pogled izgledaju slično mogu zahtijevati potpuno različitu količinu posla.

Najkorisnije je cijenu promatrati kroz ono što projekt stvarno treba, a ne samo kroz broj stranica.

Opseg projekta

Prva stvar koja utječe na cijenu je opseg.

Jednostavna poslovna stranica može sadržavati:

  • naslovnu
  • nekoliko usluga
  • o nama
  • kontakt

Drugi projekt može uključivati:

  • desetke usluga
  • portfolio
  • blog
  • više jezika
  • posebne landing stranice
  • integracije
  • napredne forme

Oba projekta nazivamo “web stranicom”, ali količina posla nije usporediva.

Zato prije procjene cijene treba definirati što se zapravo izrađuje.

Dobra početna točka je napraviti jasnu strukturu web stranice.

Broj stranica

Broj stranica ima utjecaj na cijenu, ali nije jedini kriterij.

Web s deset stranica ne mora automatski biti dvostruko skuplji od weba s pet.

Ako deset stranica koristi isti template, velik dio razvoja može se ponovno koristiti.

Primjerice:

Usluga A
Usluga B
Usluga C
Usluga D

mogu koristiti isti osnovni layout.

S druge strane, pet potpuno različitih stranica može zahtijevati više dizajna i razvoja.

Zato je važnije gledati:

  • koliko postoji različitih layouta
  • koliko je sadržaja potrebno
  • koliko je stranica specifično dizajnirano
  • postoje li posebne funkcionalnosti

Ako još niste sigurni koliko sadržaja web uopće treba imati, pročitajte koliko stranica treba imati poslovni web.

Dizajn

Dizajn može značajno utjecati na cijenu projekta.

Postoji velika razlika između:

  • jednostavne stranice bazirane na postojećem sustavu komponenti
  • potpuno individualno dizajniranog projekta
  • weba s velikim brojem posebnih animacija i interakcija

Custom dizajn zahtijeva više vremena za:

  • istraživanje
  • wireframe
  • vizualni smjer
  • dizajn komponenti
  • responsive verzije
  • revizije

To ne znači da svaki poslovni web treba biti vizualno kompleksan.

Dobar dizajn često je relativno jednostavan.

Važno je da jasno komunicira sadržaj i pomaže korisniku doći do cilja.

Gotov predložak ili custom dizajn

Korištenje gotovog predloška može smanjiti količinu potrebnog dizajnerskog i developerskog rada.

Ali postoje kompromisi.

Predložak je često potrebno prilagoditi:

  • brendu
  • sadržaju
  • strukturi
  • uslugama
  • mobilnim uređajima

Ako projekt zahtijeva puno izmjena, pokušaj prilagodbe gotovog templatea može na kraju oduzeti više vremena nego izrada odgovarajućeg sustava od početka.

Zato je važno procijeniti koliko se potrebe projekta uklapaju u postojeće rješenje.

Sadržaj

Jedan od najčešće zanemarenih dijelova cijene je sadržaj.

Netko mora pripremiti:

  • naslove
  • tekstove
  • opise usluga
  • FAQ
  • CTA-ove
  • projekte
  • podatke o tvrtki

Ako klijent dostavlja kompletan i dobro strukturiran sadržaj, količina posla je manja.

Ako treba napraviti:

  • istraživanje
  • strukturu
  • copywriting
  • uređivanje postojećih tekstova

to postaje zaseban dio projekta.

Kvalitetan sadržaj nije samo nekoliko odlomaka koji popunjavaju dizajn.

On direktno utječe na to koliko dobro web korisniku objašnjava ponudu.

Detaljnije smo to obradili u vodiču kako napisati sadržaj za web stranicu.

Fotografije i grafike

Ako klijent već ima kvalitetne fotografije i vizuale, njih možemo pripremiti za web.

Ali projekt može uključivati i:

  • profesionalno fotografiranje
  • ilustracije
  • infografike
  • obradu fotografija
  • custom ikone
  • animacije

Sve to utječe na ukupnu cijenu.

Generičke stock fotografije mogu biti jeftinije, ali nisu uvijek najbolji izbor.

Za neke djelatnosti stvarne fotografije tima, prostora ili projekata imaju puno veću vrijednost.

Funkcionalnosti

Što web ima više posebnih funkcionalnosti, to je obično skuplji.

Jednostavna poslovna stranica može imati samo:

  • navigaciju
  • kontakt formu
  • blog

Kompleksniji projekt može uključivati:

  • rezervaciju termina
  • naplatu
  • korisničke račune
  • kalkulator
  • konfigurator
  • upload dokumenata
  • filtriranje sadržaja
  • naprednu pretragu
  • članstvo
  • privatni sadržaj

Svaka funkcionalnost zahtijeva:

  • planiranje
  • razvoj
  • testiranje
  • često i buduće održavanje

Zato se cijena ne može kvalitetno procijeniti samo na temelju pitanja koliko web ima stranica.

Integracije

Web često nije izoliran sustav.

Možda ga treba povezati s:

  • CRM-om
  • newsletter platformom
  • sustavom rezervacija
  • vanjskim API-jem
  • računovodstvom
  • payment gatewayem
  • analitikom
  • chat sustavom

Jednostavna integracija može trajati vrlo kratko.

Druga može zahtijevati custom razvoj i puno testiranja.

Posebno kada dokumentacija vanjskog sustava nije kvalitetna ili API ima specifična ograničenja.

WordPress ili custom

Tehnologija također utječe na cijenu.

Za tipičan poslovni web WordPress može smanjiti trošak jer već pruža:

  • CMS
  • upravljanje korisnicima
  • uređivanje sadržaja
  • medijsku biblioteku
  • veliki broj provjerenih integracija

Kod custom projekta možda je potrebno razviti ili povezati dodatne sustave.

S druge strane, kod vrlo specifične aplikacije pokušaj izrade svega u WordPressu može biti skuplji i kompleksniji nego odgovarajuće custom rješenje.

Zato tehnologiju treba birati prema potrebama projekta.

Detaljniju usporedbu možete pronaći u članku WordPress ili custom web.

SEO

SEO može značiti vrlo različite stvari.

Kod osnovne izrade web stranice često se podrazumijevaju tehnički temelji poput:

  • titleova
  • meta podataka
  • heading strukture
  • URL-ova
  • sitemapa
  • osnovnog internog linkanja
  • optimizacije slika

Ali ozbiljniji SEO projekt može uključivati:

  • istraživanje ključnih riječi
  • analizu konkurencije
  • keyword mapping
  • content plan
  • SEO migraciju
  • structured data
  • tehnički audit

Ako se SEO uključuje tek nakon što je web završen, neke stvari treba raditi dvaput.

Zato ga je puno učinkovitije planirati tijekom samog projekta.

Redizajn starog weba

Izrada potpuno nove stranice i redizajn postojećeg weba nisu uvijek isti posao.

Kod redizajna treba razmotriti što već postoji.

Primjerice:

  • postojeći URL-ovi
  • sadržaj
  • backlinkovi
  • SEO pozicije
  • analitika
  • postojeće forme
  • korisnici

Ako web već ima organski promet, stari URL-ovi ne bi se trebali samo izbrisati.

Potrebno je planirati migraciju i redirecte kako promjena ne bi nepotrebno uzrokovala gubitak postojećih rezultata.

Takva priprema zahtijeva dodatno vrijeme, ali može sačuvati godine prethodnog SEO rada.

Više jezika

Višejezičnost također povećava opseg projekta.

Nije potrebno samo dodati gumb za promjenu jezika.

Treba riješiti:

  • prijevode
  • navigaciju
  • URL strukturu
  • SEO postavke
  • hreflang gdje je potreban
  • forme
  • sadržaj
  • održavanje prijevoda

Ako stranica ima deset stranica na hrvatskom i još englesku i njemačku verziju, količina sadržaja značajno raste.

Responsive dizajn

Mobilna verzija nije dodatak koji se radi nakon desktopa.

Web mora kvalitetno funkcionirati na različitim ekranima.

To uključuje:

  • mobitele
  • tablete
  • laptope
  • veće monitore

Elementi često zahtijevaju drugačiji raspored, veličinu i ponašanje.

Zato responsive prilagodba predstavlja stvaran dio dizajna i razvoja.

Pristupačnost

Pristupačnost web stranice također može biti dio opsega projekta.

Osnove uključuju stvari poput:

  • dovoljnog kontrasta
  • razumljive navigacije
  • pravilne HTML strukture
  • alternativnih opisa
  • korištenja tipkovnice
  • jasno označenih formi

Kod projekata sa strožim zahtjevima može biti potrebno detaljnije testiranje i dodatne prilagodbe.

Testiranje

Testiranje nije samo posljednjih deset minuta prije objave.

Treba provjeriti:

  • responsive prikaz
  • preglednike
  • linkove
  • navigaciju
  • forme
  • CTA-ove
  • analitiku
  • 404 stranice
  • osnovni SEO
  • performanse

Kod kompleksnih funkcionalnosti količina testiranja značajno raste.

Primjerice, obična kontakt forma i cijeli sustav rezervacija nisu ista stvar.

Zato QA također treba biti uključen u procjenu projekta.

Hosting i domena

Izrada web stranice nije nužno jedini trošak.

Web također treba:

  • domenu
  • hosting
  • SSL
  • backup
  • eventualne licence

Trošak može biti vrlo mali kod jednostavne stranice.

Kod web trgovina i posjećenijih sustava kvalitetniji hosting može predstavljati veći godišnji trošak.

Hosting ne treba birati samo prema najnižoj cijeni.

Važni su i:

  • performanse
  • pouzdanost
  • backup
  • podrška
  • sigurnost

Licence

Neki projekti mogu koristiti plaćene alate.

Primjerice:

  • premium pluginove
  • page buildere
  • fontove
  • stock sadržaj
  • određene integracije

Dobro je unaprijed znati jesu li te licence:

  • uključene u cijenu
  • godišnje
  • jednokratne
  • vezane uz održavanje

Mali godišnji troškovi mogu se s vremenom nakupiti ako web ovisi o velikom broju različitih alata.

Održavanje nakon objave

Web treba održavati i nakon što ode online.

Kod WordPressa to može uključivati:

  • ažuriranja
  • backup
  • sigurnosne provjere
  • monitoring
  • manje izmjene
  • provjeru funkcionalnosti

Kod custom weba također treba održavati frameworke, dependencies, hosting i integracije.

Zato kod ukupnog budžeta treba razmišljati o trošku kroz nekoliko godina, a ne samo o početnoj cijeni projekta.

Zašto su ponude različite?

Klijent može poslati isti upit trima izvođačima i dobiti potpuno različite cijene.

Jedan može ponuditi 500 eura.

Drugi 1.500.

Treći 5.000.

To ne znači automatski da je najjeftiniji loš ili najskuplji najbolji.

Ponude možda jednostavno ne uključuju iste stvari.

Primjerice, jedna ponuda može uključivati:

  • gotov template
  • unos dostavljenog sadržaja
  • kontakt formu

Druga može uključivati:

  • analizu poslovanja
  • strukturu weba
  • custom dizajn
  • copywriting
  • SEO
  • testiranje
  • podršku nakon objave

Zato ponude treba uspoređivati prema opsegu, a ne samo prema konačnom broju.

Što pitati prije odluke?

Prije prihvaćanja ponude korisno je provjeriti:

  • što je točno uključeno
  • tko priprema sadržaj
  • je li dizajn custom
  • koliko revizija postoji
  • je li web responsive
  • što uključuje SEO
  • tko unosi sadržaj
  • je li hosting uključen
  • postoje li dodatne licence
  • što se događa nakon objave
  • možete li sami uređivati sadržaj

Tako ćete puno lakše usporediti dvije ponude koje na prvi pogled izgledaju potpuno različito.

Koliko onda košta web?

Za jednostavnije poslovne web stranice cijena može krenuti od nekoliko stotina eura.

Kompleksniji projekti s više sadržaja, custom dizajnom i dodatnim funkcionalnostima često ulaze u nekoliko tisuća eura.

Web aplikacije i kompleksne trgovine mogu biti značajno skuplje.

Ali sama brojka bez opisa projekta ne govori puno.

Puno je korisnije pitati:

Što dobivam za taj budžet?

i:

Hoće li to rješenje odgovarati mojim potrebama i za dvije ili tri godine?

Kako smanjiti trošak?

Najjednostavniji način nije tražiti da se sve napravi jeftinije.

Bolje je smanjiti nepotrebnu kompleksnost.

Primjerice:

  • krenuti s manjim brojem važnih stranica
  • pripremiti sadržaj unaprijed
  • koristiti konzistentan design system
  • izbaciti funkcionalnosti koje nisu potrebne
  • koristiti postojeća kvalitetna rješenja gdje imaju smisla
  • projekt podijeliti u faze

To omogućuje da se budžet usmjeri na stvari koje stvarno stvaraju vrijednost.

Dobra priprema projekta često smanjuje i cijenu i vrijeme potrebno za izradu.

Cijena treba pratiti cilj

Web stranica ne bi se trebala promatrati samo kao trošak.

Ako poslovni web treba donositi nove upite, treba procijeniti njegovu vrijednost u odnosu na potencijalne rezultate.

Web od 500 eura koji ne donese niti jedan kvalitetan upit može biti skuplji od weba od nekoliko tisuća eura koji godinama generira nove klijente.

Naravno, veći budžet ne jamči rezultat.

Ali odluku treba donositi prema poslovnom cilju, a ne samo prema najnižoj početnoj cijeni.

Ako još niste definirali što web treba postići, krenite od vodiča kako odrediti ciljeve web stranice.
