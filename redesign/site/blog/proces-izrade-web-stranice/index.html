Kako izgleda proces izrade web stranice

Izrada web stranice često se svodi na pitanje dizajna: koje će boje koristiti, kako će izgledati naslovna stranica i gdje će se nalaziti fotografije.

Izrada web stranice često se svodi na pitanje dizajna: koje će boje koristiti, kako će izgledati naslovna stranica i gdje će se nalaziti fotografije.

U praksi kvalitetna web stranica nastaje puno prije nego što počne vizualni dizajn.

Prije prve linije koda potrebno je razumjeti poslovanje, definirati što web treba postići, odrediti kome se obraća, isplanirati strukturu stranica i sadržaj te odlučiti kako će korisnik doći od prvog posjeta do upita, poziva ili kupnje.

Zato proces izrade web stranice možemo podijeliti u nekoliko povezanih faza:

  1. upoznavanje poslovanja i definiranje ciljeva
  2. analiza tržišta i konkurencije
  3. istraživanje korisnika i ključnih riječi
  4. planiranje strukture web stranice
  5. planiranje sadržaja i korisničkog iskustva
  6. vizualni dizajn
  7. razvoj web stranice
  8. SEO optimizacija
  9. testiranje
  10. objava
  11. praćenje i održavanje

Svaka od tih faza utječe na krajnji rezultat.

Web stranica može izgledati odlično, ali ako korisnik ne može pronaći ono što traži, neće ostvariti svoj cilj. Može biti tehnički savršena, ali ako sadržaj ne odgovara na pitanja potencijalnog kupca, neće donositi mnogo upita.

Zato dobar web projekt treba promatrati kao cjelinu.

1. Definiranje cilja web stranice

Prvo pitanje nije:

Kako bi web trebao izgledati?

Prvo pitanje je:

Što želimo da web stranica napravi za poslovanje?

Cilj se razlikuje od projekta do projekta.

Web stranica može prvenstveno služiti za:

  • generiranje novih upita
  • telefonske pozive
  • rezervacije termina
  • prodaju proizvoda
  • prezentaciju usluga
  • izgradnju povjerenja
  • prikupljanje potencijalnih klijenata
  • edukaciju korisnika
  • pozicioniranje tvrtke kao stručnjaka u svojem području

Primjerice, web stranica lokalnog obrtnika koji želi više telefonskih poziva trebala bi biti organizirana drugačije od web stranice konzultantske tvrtke koja prodaje kompleksnu B2B uslugu.

Kod prvog će jedan od najvažnijih elemenata biti brz pristup kontaktu, lokaciji i uslugama.

Kod drugog će korisniku možda trebati više informacija, reference, projekti, objašnjenje procesa i odgovori na česte nedoumice prije nego što pošalje upit.

Bez jasno definiranog cilja lako je napraviti web koji izgleda dobro, ali nema jasno određenu funkciju.

2. Razumijevanje poslovanja i korisnika

Prije planiranja stranica potrebno je razumjeti samo poslovanje.

To uključuje pitanja poput:

  • Koje usluge ili proizvode tvrtka nudi?
  • Koje su usluge najvažnije?
  • Tko je idealan klijent?
  • Koje probleme korisnik pokušava riješiti?
  • Zašto bi odabrao ovu tvrtku umjesto konkurencije?
  • Što korisnik mora znati prije nego što pošalje upit?
  • Postoje li česte nedoumice ili prigovori?
  • Kako trenutno dolaze novi klijenti?

Ovi odgovori kasnije utječu na gotovo svaki dio web stranice.

Ako korisnike najviše zanima cijena, web ne bi trebao skrivati sve informacije o cijenama iza kontakt forme.

Ako je najveća prepreka povjerenje, potrebno je naglasiti iskustvo, projekte, recenzije, proces rada ili druge dokaze stručnosti.

Ako korisnici ne razumiju razliku između nekoliko usluga, struktura i sadržaj moraju tu razliku jasno objasniti.

Drugim riječima, dobra web stranica ne nastaje samo iz dizajnerskih odluka. Ona nastaje iz razumijevanja poslovanja i ljudi kojima je namijenjena.

3. Analiza konkurencije

Analiza konkurencije nije proces kopiranja tuđih web stranica.

Cilj je razumjeti kako se druge tvrtke u istoj industriji predstavljaju korisnicima.

Gledamo, primjerice:

  • kako su organizirali usluge
  • koje informacije ističu
  • kakve pozive na akciju koriste
  • koliko detaljno objašnjavaju svoje usluge
  • koriste li cijene
  • prikazuju li projekte i reference
  • koje probleme korisnika naglašavaju
  • kakvu strukturu imaju njihove web stranice
  • gdje postoje prilike za bolji sadržaj ili korisničko iskustvo

Posebno je korisno pronaći ono što konkurencija ne radi dobro.

Ako gotovo sve konkurentske stranice imaju vrlo šture opise usluga, kvalitetan detaljan sadržaj može biti velika prednost.

Ako korisnik na konkurentskim webovima teško pronalazi cijenu, proces ili informacije o tome što je uključeno u uslugu, to je prilika da vlastita stranica bude jasnija.

4. Istraživanje korisnika i ključnih riječi

SEO istraživanje ne radi se tek kada je web već završen.

Rezultati istraživanja ključnih riječi mogu utjecati na samu strukturu web stranice.

Primjerice, ako tvrtka nudi nekoliko različitih usluga koje korisnici zasebno pretražuju, često ima smisla da svaka od tih usluga dobije vlastitu stranicu.

Ključne riječi također pomažu razumjeti kako potencijalni klijenti opisuju svoje probleme.

Tvrtka može interno koristiti jedan naziv za uslugu, dok korisnici na Googleu koriste potpuno drugi izraz.

Zato istraživanje nije samo pitanje volumena pretrage. Ono pomaže odgovoriti na pitanja:

  • što ljudi traže
  • kako formuliraju problem
  • koje informacije očekuju
  • kakva je namjera iza pretrage
  • koje teme zaslužuju zasebne stranice

SEO zbog toga treba biti dio planiranja web stranice, a ne nešto što se pokušava dodati nakon što je sve već napravljeno.

5. Planiranje strukture web stranice

Nakon što razumijemo poslovanje, korisnike i sadržaj, možemo definirati strukturu weba.

Za jednostavnu poslovnu web stranicu ona bi mogla izgledati ovako:

Naslovna
├── Usluge
│   ├── Usluga A
│   ├── Usluga B
│   └── Usluga C
├── Projekti
├── O nama
├── Blog
└── Kontakt

Naravno, prava struktura ovisi o poslovanju.

Jedna od čestih grešaka je stavljanje svih usluga na jednu kratku stranicu.

Ako tvrtka nudi nekoliko važnih i dovoljno različitih usluga, zasebne stranice omogućuju:

  • detaljnije predstavljanje svake usluge
  • bolju SEO optimizaciju
  • jasnije korisničko iskustvo
  • lakše interno povezivanje sadržaja
  • preciznije oglašavanje
  • kvalitetnije odgovaranje na pitanja korisnika

Struktura također treba biti dovoljno jednostavna da korisnik brzo shvati gdje se nalazi i kamo može dalje.

Navigacija nije mjesto na kojem treba pokazivati kreativnost pod svaku cijenu. Ako korisnik mora razmišljati gdje će pronaći određenu informaciju, struktura vjerojatno nije dovoljno jasna.

6. Planiranje sadržaja i wireframe

Prije finalnog dizajna korisno je definirati raspored sadržaja.

Tu dolazimo do wireframea.

Wireframe je pojednostavljeni prikaz stranice koji pokazuje:

  • redoslijed sekcija
  • hijerarhiju informacija
  • mjesto naslova
  • pozive na akciju
  • slike
  • forme
  • reference
  • FAQ
  • ostale ključne elemente

U toj fazi ne bavimo se prvenstveno bojama, fontovima i vizualnim detaljima.

Bavimo se pitanjem:

Koju informaciju korisnik treba vidjeti sljedeću?

Primjerice, tipična stranica usluge može imati:

  1. jasan naslov i glavnu vrijednost usluge
  2. problem koji korisnik pokušava riješiti
  3. objašnjenje usluge
  4. što je uključeno
  5. način rada
  6. rezultate ili reference
  7. cijenu ili način formiranja cijene
  8. česta pitanja
  9. završni poziv na akciju

Dobro korisničko iskustvo često nije rezultat spektakularnih animacija, nego dobrog rasporeda informacija.

7. Priprema sadržaja

Tekst i dizajn web stranice trebaju nastajati zajedno.

Jedna od čestih grešaka je napraviti kompletan dizajn koristeći privremeni tekst, a stvarni sadržaj ubaciti tek na kraju.

Tada se često dogodi da:

  • pravi naslovi ne odgovaraju dizajnu
  • sekcije imaju premalo ili previše sadržaja
  • važne informacije nemaju odgovarajuće mjesto
  • stranica vizualno izgleda dobro, ali komunikacijski ne funkcionira

Sadržaj bi trebao jasno odgovoriti na pitanja korisnika.

Umjesto općenitih poruka poput:

Pružamo kvalitetna i profesionalna rješenja prilagođena vašim potrebama.

korisnije je konkretno objasniti:

  • što radite
  • za koga
  • koji problem rješavate
  • što korisnik dobiva
  • kako izgleda proces
  • koliko traje
  • koliko približno košta
  • zašto vam može vjerovati

Kvalitetan sadržaj često ima veći utjecaj na rezultat web stranice od vizualnih efekata.

8. Vizualni dizajn

Tek nakon što su definirani struktura, sadržaj i prioriteti dolazimo do detaljnog vizualnog dizajna.

Tu definiramo:

  • boje
  • tipografiju
  • stil fotografija i grafika
  • gumbe
  • forme
  • kartice
  • razmake
  • vizualnu hijerarhiju
  • način prikaza na različitim veličinama ekrana

Dizajn ne bi trebao služiti samo tome da web izgleda moderno.

Njegova je funkcija pomoći korisniku da razumije sadržaj.

Dobar dizajn jasno pokazuje:

  • što je najvažnije
  • što je povezano
  • gdje treba kliknuti
  • što je naslov
  • što je dodatna informacija
  • gdje počinje nova tema

Ako je sve veliko, šareno i vizualno naglašeno, tada ništa zapravo nije naglašeno.

9. Razvoj web stranice

Kada je dizajn definiran, kreće razvoj.

Ovisno o projektu, to može uključivati:

  • izradu responsive layouta
  • razvoj komponenti
  • postavljanje CMS-a
  • kontakt forme
  • integraciju analitike
  • newsletter
  • CRM integracije
  • povezivanje vanjskih servisa
  • cookie consent
  • optimizaciju performansi
  • sigurnosne postavke

Posebno je važno da se web ne razvija samo za veliki desktop ekran.

Danas stranica mora kvalitetno funkcionirati na različitim uređajima i veličinama ekrana.

Element koji izgleda dobro na monitoru od 27 inča može biti potpuno nepraktičan na mobilnom telefonu.

Zato responsive dizajn nije samo smanjivanje elemenata, nego prilagođavanje iskustva korisniku i uređaju koji koristi.

Ako planirate novi poslovni web, više informacija o našim paketima, procesu i početnim cijenama možete pronaći na stranici izrada web stranica.

10. SEO optimizacija prije objave

SEO ne završava dodavanjem nekoliko ključnih riječi u tekst.

Prije objave potrebno je provjeriti barem osnovne tehničke i sadržajne elemente.

To uključuje:

  • jedinstven title za svaku važnu stranicu
  • meta description
  • pravilnu strukturu H1, H2 i H3 naslova
  • jasne i kratke URL-ove
  • interne linkove
  • alt opise važnih slika
  • optimizaciju veličine slika
  • canonical oznake gdje su potrebne
  • XML sitemap
  • robots.txt
  • pravilnu indeksaciju
  • redirecte kod zamjene postojećih URL-ova
  • strukturirane podatke gdje imaju smisla

Kod redizajna postojeće web stranice SEO je posebno važan.

Promjena URL strukture bez pravilnih redirekcija može dovesti do gubitka postojećih pozicija i prometa.

Zato SEO treba uključiti u projekt prije objave, a ne nakon što se pojavi problem.

11. Optimizacija brzine

Brzina utječe na korisničko iskustvo, ali i na tehničku kvalitetu web stranice.

Najčešći problemi uključuju:

  • prevelike slike
  • nepotrebne skripte
  • previše vanjskih resursa
  • loše učitavanje fontova
  • preveliku količinu JavaScripta
  • spor hosting
  • nedostatak cacheiranja

Važno je pritom ne gledati samo jedan broj iz alata za testiranje.

Cilj nije dobiti savršen rezultat na screenshotu, nego napraviti web koji se stvarnim korisnicima učitava brzo i stabilno.

12. Testiranje web stranice

Prije objave potrebno je provjeriti radi li sve što očekujemo.

Testiranje uključuje više od otvaranja naslovne stranice i provjere izgleda.

Provjeravamo, između ostalog:

  • navigaciju
  • sve važne linkove
  • kontakt forme
  • gumbe
  • responsive prikaz
  • mobilne uređaje
  • različite preglednike
  • slike
  • 404 stranice
  • redirecte
  • osnovnu pristupačnost
  • analitiku
  • SEO postavke
  • performanse

Posebno je važno testirati elemente koji imaju poslovnu vrijednost.

Ako kontakt forma ne šalje poruke, korisniku nije posebno važno što web ima lijepu animaciju u hero sekciji.

13. Objava web stranice

Kada su sadržaj, dizajn, razvoj i testiranje završeni, web se može objaviti.

Ovisno o projektu, objava može uključivati:

  • postavljanje produkcijskog hostinga
  • povezivanje domene
  • DNS postavke
  • SSL certifikat
  • migraciju postojeće stranice
  • redirecte
  • ponovno testiranje formi
  • slanje XML sitemapa Googleu
  • provjeru Google Search Consolea
  • provjeru analitike

Kod nove domene proces je relativno jednostavan.

Kod zamjene postojećeg weba potrebno je biti puno pažljiviji jer promjene mogu utjecati na postojeći promet, URL-ove i pozicije na Googleu.

14. Web stranica nije završena objavom

Jedna od najvećih zabluda je da projekt završava onog trenutka kada web postane dostupan javnosti.

Objava je zapravo početak razdoblja u kojem možemo vidjeti kako stvarni korisnici koriste stranicu.

Nakon objave možemo pratiti:

  • koje stranice ljudi najviše posjećuju
  • odakle dolaze
  • koje stranice donose upite
  • gdje korisnici odustaju
  • što pretražuju
  • koje stranice Google indeksira
  • koje ključne riječi počinju donositi prikaze
  • rade li sve forme i integracije

Na temelju tih podataka web se može dalje poboljšavati.

Osim toga, potrebno je redovno održavati tehnički dio stranice, izrađivati sigurnosne kopije, pratiti dostupnost i ažurirati sustav kada je potrebno.

Web stranica zato nije jednokratni proizvod koji se jednom napravi i više ne dira.

Ona je dio poslovnog sustava koji se treba razvijati zajedno s poslovanjem.

Koliko traje izrada web stranice?

Ne postoji jedan rok koji vrijedi za svaki projekt.

Na trajanje najviše utječu:

  • broj stranica
  • kompleksnost dizajna
  • količina sadržaja
  • posebne funkcionalnosti
  • integracije
  • dostupnost fotografija i materijala
  • brzina povratnih informacija
  • broj revizija

Jednostavnija poslovna web stranica može biti završena kroz nekoliko tjedana, dok kompleksniji projekti mogu trajati nekoliko mjeseci.

Često najveće kašnjenje ne uzrokuje razvoj, nego čekanje sadržaja, fotografija ili povratnih informacija.

Zbog toga je kvalitetna priprema prije početka projekta izuzetno važna.

Što čini kvalitetan proces izrade web stranice?

Kvalitetan proces nije nužno onaj koji ima najviše koraka.

Važno je da se odluke donose pravim redoslijedom.

Prvo treba razumjeti:

što web treba postići i kome služi.

Zatim definirati:

koje informacije i stranice su potrebne.

Tek nakon toga ima smisla odlučivati:

kako će sve izgledati i kako će biti tehnički izvedeno.

Takav pristup smanjuje naknadne promjene i povećava vjerojatnost da će konačna stranica imati stvarnu poslovnu vrijednost.

Trebate novu web stranicu?

Ako planirate novu web stranicu ili razmišljate o zamjeni postojeće, krenite od cilja koji želite postići, a ne od odabira boja i predloška.
